## ⚡ Autonomous AI Pipeline Visualizer

A representation of the multi-model AI pipeline built for **Tracks & Taps**. It ingests raw CSV theme definitions, discovers landmarks, geocodes coordinates, solves Traveling Salesperson Problem (TSP) walking routes, verifies quality, generates engaging narratives, and publishes production-ready tours on autopilot.

### 🖥️ Simulated Execution Trace
```text
📥 [1/8] INGEST  ─── Ingested Rome CSV row
🔍 [2/8] SEARCH  ─── Discovered landmarks & gems
📍 [3/8] GEOMAP  ─── Geocoded coordinates (Photon API)
🚲 [4/8] ROUTE   ─── Solved TSP walking route
🛡️ [5/8] VERIFY  ─── Injected 4 missed sights & quality metrics
✍️ [6/8] WRITE   ─── Generated story, riddles & pub golf games
📸 [7/8] COVER   ─── Fetched curated Unsplash cover image
🚀 [8/8] PUBLISH ─── Synced complete tour to Supabase DB
```
